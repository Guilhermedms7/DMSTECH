# DMSTECH Store

Projeto front-end de uma loja virtual de produtos de tecnologia. O catálogo inclui páginas de computadores, hardware e periféricos, além de telas de produto, carrinho, checkout, login, conta, contato e apresentação da loja.

## Tecnologias

- HTML
- CSS

## Estrutura

- `DMSSTORE1.0/DMS1.0/` — páginas e estilos da loja
- `DMSSTORE1.0/IMG/` — imagens

## Visualizar localmente

Abra `DMSSTORE1.0/DMS1.0/index.html` em um navegador.
